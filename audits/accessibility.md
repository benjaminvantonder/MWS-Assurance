# Accessibility Checklist — MWS Group Website

## Perceivable

| Criteria | Status |
|----------|--------|
| Non-text content has text alternatives | ✅ |
| Captions provided for multimedia | N/A |
| Info and relationships preserved in structure | ✅ |
| Meaningful sequence of content | ✅ |
| Colour not used as sole means of conveying info | ✅ |
| Contrast ratio ≥ 4.5:1 (normal text) | ✅ |
| Contrast ratio ≥ 3:1 (large text) | ✅ |
| Text can be resized without assistive tech | ✅ |
| Images of text not used | ✅ |

## Operable

| Criteria | Status |
|----------|--------|
| All functionality available via keyboard | ✅ |
| Focus order preserves meaning/operability | ✅ |
| Visible focus indicator | ✅ |
| No keyboard trap | ✅ |
| Page titles describe purpose | ✅ |
| Skip content link available | N/A (single page) |
| Link purpose identifiable | ✅ |
| Headings and labels descriptive | ✅ |
| No seizure-inducing flashes | ✅ |
| Motion animations can be disabled (`prefers-reduced-motion`) | ✅ |

## Understandable

| Criteria | Status |
|----------|--------|
| Language attribute on HTML element | ✅ |
| No unusual words/abbreviations defined | ✅ |
| Input assistance provided | ✅ |
| Consistent navigation | ✅ |
| Consistent identification | ✅ |
| Error identification | ✅ |

## Robust

| Criteria | Status |
|----------|--------|
| HTML elements have complete start/end tags | ✅ |
| IDs unique | ✅ |
| ARIA attributes valid | ✅ |
| Status messages announced by AT | ✅ |
